# Arena artwork sources

Selected using the user’s Three.js Poly Asset Library guide. Downloaded 2026-09-06. All runtime images are hosted with the game; original pack archives are not deployed. Unmodified 1K JPG material maps and 512-pixel PNG particle textures are used.
